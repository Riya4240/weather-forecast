# 🌦️ Weather Forecast Website

## 📌 Overview
A responsive weather forecasting website that allows users to search for any city and view real-time weather information.

## 🚀 Features
- Search weather by city name
- Displays temperature and weather conditions
- Responsive design
- Easy-to-use interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## 📂 Project Structure
```
Weather-Forecast/
│── index.html
│── css/
│── js/
│── images/
│── README.md
```

## ▶️ How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Enter a city name to view the weather forecast.
